## v7 Evidence Artifact Schemas

Formal verification evidence is generated by `bash tools/verify_formal.sh` and stored in
`target/formal-evidence/latest/`. Each artifact conforms to a versioned JSON schema.

### `verus.json` — Verus Formal Verification

```json
{
  "schema": "verus-v1",
  "date": "ISO-8601",
  "lemmas_verified": 50,
  "lemmas_failed": 0,
  "errors": 0,
  "command": "RUSTUP_TOOLCHAIN=1.95.0-x86_64-unknown-linux-gnu /tmp/verus-install/verus-x86-linux/verus ecu-spec/proofs/verus.rs"
}
```

**Command:** `RUSTUP_TOOLCHAIN=1.95.0-x86_64-unknown-linux-gnu /tmp/verus-install/verus-x86-linux/verus ecu-spec/proofs/verus.rs`
**Pass criteria:** `verification results:: N verified, 0 errors`

### `coverage.json` — Code Coverage Gate (≥90% per crate)

```json
{
  "schema": "coverage-v1",
  "date": "ISO-8601",
  "gate": "per-crate-coverage-90",
  "crates": {
    "ecu-spec":         { "coverage_percent": <float>, "gate_met": true|false },
    "ecu-runtime":      { "coverage_percent": <float>, "gate_met": true|false },
    "ecu-scheduler":    { "coverage_percent": <float>, "gate_met": true|false },
    "ecu-core":         { "coverage_percent": <float>, "gate_met": true|false }
  }
}
```

**Command:** `cargo llvm-cov` per crate
**Pass criteria:** `coverage_percent ≥ 90.0` for each production crate

### `benchmarks.json` — Performance Regression Gate (p95 ≤5%)

```json
{
  "schema": "benchmarks-v1",
  "date": "ISO-8601",
  "gate": "p95-regression-5pct",
  "benchmarks": {
    "<name>": {
      "p95_ns": <int>,
      "baseline_p95_ns": <int>,
      "regression_pct": <float>,
      "gate_met": true|false
    }
  }
}
```

**Pass criteria:** `regression_pct ≤ 5.0` for all benchmarks

### `conformance.json` — Proof-to-Product Conformance

```json
{
  "schema": "conformance-v1",
  "date": "ISO-8601",
  "gate": "zero-blocked-rows",
  "result": "PASS",
  "blocked_count": 0,
  "map_file": "aidocs/proof-to-product-conformance-map.md"
}
```

**Pass criteria:** `blocked_count == 0`

## Proof Activation Contract

Kani and Verus proofs are activated by their tools' cfgs (`cfg(kani)` and
`cfg(verus)`), not by public Cargo features. `ecu-spec` intentionally does not
publish empty proof features; use the tool commands in this file as the proof
entrypoints.
